### GitHub Pages公開の要点

1. GitHubでリポジトリを作成
2. `index.html` がリポジトリ直下に来るようゲームフォルダの中身をアップロード
3. `Settings > Pages` で `Deploy from a branch` を選択
4. `main` / `/(root)` を選択して公開

通常は `https://ユーザー名.github.io/リポジトリ名/` でアクセスできます。

### ホーム画面へ追加

Android Chromeではブラウザメニューの「インストール」またはゲーム内設定のインストールボタンを使用します。iPhoneではSafariの共有メニューから「ホーム画面に追加」を選びます。
ブラウザで動く、AI戦闘ロボットを3年間育成して世代交代を続けるローグライク育成ゲームです。

## セーブについて

ゲーム進行データはlocalStorageへ自動保存され、JSONで書き出し / 読み込みできます。

マネージャー画像・名前・性格はゲームセーブとは別のlocalStorage領域へ保存します。そのため別ゲームセーブを読み込んでも同じマネージャーを使用できます。

## 起動

### Windows（推奨）

ZIPを展開し、ゲームフォルダ内の `START_GAME.bat` をダブルクリックしてください。

1. ローカルサーバーが自動起動します。
2. ブラウザで `http://127.0.0.1:8765/index.html` が自動的に開きます。
3. プレイ中は黒いサーバー画面を開いたままにしてください。
4. 終了時は `Ctrl+C` または黒い画面を閉じてください。

Python 3 が必要です。`START_GAME.bat` は `py`、見つからなければ `python` を自動的に使用します。

### 手動起動

`index.html` はES Modulesを利用するため、ゲームフォルダ内で簡易HTTPサーバーを起動してください。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000/index.html` を開きます。
